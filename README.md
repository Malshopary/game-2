# 🌾 لعبة مزرعة الأحلام ثلاثية الأبعاد (3D Retro Pixel Farm)

لعبة محاكاة زراعية ثلاثية الأبعاد (3D Isometric) بأسلوب البكسل الكلاسيكي (Retro Pixel Art) مستوحاة من ألعاب مثل **Stardew Valley** و **Harvest Moon**، مبنية بالكامل باستخدام **Three.js** و **Vite** و **JavaScript**.

---

## ✨ المميزات الرئيسية (Key Features)

1. **الزراعة والحصاد التفاعلي (Farming System):**
   - حرث الأرض بالفأس ⛏️، وسقي التربة بالمرشة 💧، وزرع البذور 🌱، وحصاد المحاصيل الناضجة بالمنجل 🌾.
   - تنوع كبير في المحاصيل مع مراحل نمو ديناميكية واقعية ثلاثية الأبعاد وعدادات نضج حية.

2. **تحريك الشاشة عند أطراف الشاشة (Screen Edge Panning):**
   - حركة كاميرا سلسة وديناميكية عند تحريك مؤشر الماوس إلى حواف الشاشة الأربعة (يمين، يسار، أعلى، أسفل).
   - عودة وتمركز تلقائي ناعم للكاميرا على المزارع بمجرد بدء الحركة.

3. **وضع حركة الشخصية المخصص (Walk Mode):**
   - زر خاص للتحكم في حركة الشخصية وتوجيهها بالنقر أو السحب بحرية تامة دون خطر حدوث أي إجراءات زراعية أو ري بالخطأ.
   - أزرار حركة مباشرة إضافية على الشاشة (D-Pad) ودعم كامل لأزرار لوحة المفاتيح (WASD والأسهم).

4. **نظام توسيع ونقل الأحواض وتعديل الطرق:**
   - **إضافة أحواض حرة:** إمكانية شراء ووضع أحواض زراعية جديدة في أي مكان على المساحة الخضراء (50 ذهب للحوض، كميات غير محدودة).
   - **نقل الأحواض:** تحريك أي حوض وإعادة ترتيبه بحرية مع نظام منع التداخل الذكي.
   - **تعديل الطرق:** تحكم كامل بمربعات الطريق الحجرية (نقل، مسح لإعادة العشب، رصف مربعات جديدة).
   - **قوالب تقسيم الأرض:** خيارات جاهزة لترتيب أحواض الزراعة (شبكة منتظمة، صفوف طولية، مربعات، ومصاطب).

5. **عالم حيوي وتفاعلي (Living World & Animals):**
   - حظائر وحيوانات ثلاثية الأبعاد تفاعلية وذكاء اصطناعي ذاتي (أبقار، خراف، دجاج، بط في البحيرة، ماعز جبلي، أرانب، وأحصنة).
   - أحواض طعام وماء ذكية تتجه الحيوانات لتناول الطعام منها.
   - حيوانات أليفة محبوبة تتجول في المزرعة (كلب وقطة) مع إمكانية مداعبتهم لكسب الطاقة والخبرة.
   - بحيرة حية بأسماك متحركة ونباتات لوتس وقصب مائي وجسر صيد خشبي.

6. **طقس وإضاءة ومؤثرات جوية ديناميكية:**
   - دورة ليل ونهار كاملة وساعة تقويم فصول.
   - طقس متغير (مشمس، ممطر، عاصف مع صواعق، ثلجي، ورياح متساقطة الأوراق) مع تأثير مباشر على ري وسرعة نمو المحاصيل.
   - نظام دقة بكسل مخصص بضغطة زر (2x واضح الملامح، 1x HD، 3x، 4x) أو مفتاح `P`.

7. **صوتيات وموسيقى تصويرية:**
   - موسيقى هادئة مريحة للمزرعة ومؤثرات صوتية لكافة الأفعال (حرث، ري، حصاد، خطوات، عملات، وغيرها).

## 🚀 تشغيل اللعبة محلياً (Run Locally)

### المتطلبات (Prerequisites)
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)

### الخطوات:
```bash
# 1. استنساخ المستودع
git clone https://github.com/Malshopary/game-2.git

# 2. الدخول لمجلد المشروع
cd game-2

# 3. تثبيت الحزم
npm install

# 4. تشغيل خادم التطوير
npm run dev
```

أو تشغيل ملف `play-game.bat` مباشرة على نظام ويندوز لبدء اللعبة وفتحها في المتصفح تلقائياً!

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Three.js:** محرك الرسوميات ثلاثية الأبعاد والمؤثرات البصرية.
- **Vite:** خادم وأداة بناء فائقة السرعة.
- **Vanilla JavaScript & CSS:** بنية مرنة وتصميم Stardew Valley خشبي راقٍ.
- **Canvas-Confetti & GSAP:** أنيميشن احتفالي واحترافي.
